# Research Lab

A daily research workspace: exploring topics, running small experiments, and
recreating published papers to understand how they work — one commit at a time.

## Structure

| Folder | What goes here |
|--------|----------------|
| [`journal/`](journal/) | Daily lab notebook — what we explored, learned, and left open, one file per day |
| [`topics/`](topics/) | Topic deep-dives — notes plus small runnable code to build intuition |
| [`papers/`](papers/) | Paper recreations — each paper gets its own folder with notes, code, and results |
| [`projects/`](projects/) | Small standalone projects that grew beyond a single experiment |

## Conventions

- **Everything is reproducible**: each paper/project folder documents how to run it.
- **Journal first**: every session ends with a journal entry — even a short one.
- **One folder = one idea**: a paper recreation or topic lives in its own folder
  with its own README, so any folder makes sense on its own.
- **Small over perfect**: minimal recreations that capture the core idea beat
  full-scale reproductions.
