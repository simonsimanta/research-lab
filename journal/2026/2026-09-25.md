## What we learned (shareable)

- Verify before you trust: three of my own first-pass results were wrong (a fabricated link, an HTML error page
  saved as a "PDF", and ancillary files mistaken for guidelines). Cheap checks (file header/end marker, page count,
  reading the licence text) caught all of them.
- Government sites move; old document links rot. Snapshotting + hashing sources and tracking versions is a
  requirement for any guideline-grounded system, not an extra.
- For clinical knowledge bases the licence, not the download, is the gating factor.
- A useful pipeline shape for document-to-knowledge-graph ingestion: per-format parsing → clause-level segmentation →
  LLM extraction into a strict schema → quote-verified provenance → expert review → versioned graph.
